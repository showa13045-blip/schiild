# Schiild — スマートフォン向け試作版

1日1枚の写真を端末に記録する Expo / React Native アプリです。
添付資料に沿ったモバイル体験を実装しています。T01〜T12全体が完成した本番SNSではありません。

## 起動

Node.js 22.13以降、pnpm 11、および対応する Expo Go を用意してください。

```sh
pnpm install --frozen-lockfile
pnpm dev:mobile
```

スマートフォンとPCを同じネットワークに接続し、ターミナルに出るQRコードをExpo Goで読み取ります。
このPCでは依存関係を取得済みです。`start-mobile.cmd` からも起動できます。
Expo SDK 57を使用しています。ストアのExpo GoがSDKに対応していない場合は、対応する開発ビルドが必要です。

## 使い方

1. アトリエの名前と定員を入力します。
2. 「今日のシールを撮る」からカメラを許可します。
3. 撮影画像を確認し、記録先のアトリエを選択します。
4. 確認画面で記録を確定します。確定後の差し替えはできません。
5. アーカイブで記録を確認します。同じ日のシールは追加のアトリエにも記録できます。

撮影後は1080×1080のJPEG、品質85%に正規化します。端末のアプリ専用領域に保存し、写真ライブラリには追加しません。
撮影済みの未確定画像は再起動後も復元します。日付をまたいだ画像は新しい日の記録として扱いません。

## 実装済み

- ホーム、アトリエ作成・詳細、カメラ・撮影確認、シール詳細、アーカイブ、マイページ、設定
- UTC日付で1日1枚の制約、確認画面、多重タップ防止
- 同じシールの追加アトリエへの記録
- カメラ権限拒否、空状態、保存失敗、データ読み込み失敗
- JST / UTC表示切り替えと対象時間の窓
- 端末内のデータ削除、ライトモード、角丸のない写真表示
- 共有型、色トークン、暫定文言集、文言検査、ドメインテスト

## 未接続

認証、他の人の参加、サーバー投稿・同期、NestJS API、PostgreSQL、Rust / WASM生成、抽選、開封、日次配信、アカウント削除。
生成されていない作品を仮画像で置き換えることはしていません。
ローカル保存はサーバー投稿の代替ではなく、複数端末にわたる1日1枚を保証しません。
アプリをアンインストールすると端末内の記録は失われます。

不足資料と差分は `docs/IMPLEMENTATION.md` を参照してください。

## 検証

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

`pnpm build` はiOS / Android用JavaScript・アセットの書き出しです。APK / IPAの作成、署名、実機検証とは異なります。

## 構成

```text
apps/mobile/         Expoアプリ
packages/shared/     日付と記録のルール、型、文言、デザイントークン
scripts/             文言検査
tests/               ドメインテスト
docs/                仕様差分と検証結果
```

## PCで操作する

`start-pc.cmd` を起動し、PCのブラウザで http://localhost:8083 を開きます。Expo GoへのログインやQRコードは不要です。
ブラウザ版の記録はIndexedDBに保存され、スマートフォン版の記録とは別です。
カメラ撮影にはWebカメラとブラウザのカメラ許可が必要です。ブラウザデータを消去すると記録も失われます。

正式資料を受領し、Rustの基盤検証も成功しています。GitHub CIとpush確認が残っています。詳細はdocs/M0-REPORT.mdとdocs/SOURCE-REVIEW.mdを参照してください。

このPCの作業フォルダ内に導入したRustの検証は `pnpm test:rust` で再実行できます。他の環境ではPATH上のcargoを使用します。
