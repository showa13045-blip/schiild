作成にあたり公開情報を調査していますが、法令の解釈・当てはめは有資格者の判断が必要です。

## A. ★退会後もシールトに区画が残ること

### 事実関係

- Schiildは、複数ユーザーの写真から1枚の合成作品（シールト）を毎日生成する
- 生成後の作品は「描き直さない」ことを設計原則としている（要件定義書 §4.7）
- ユーザーが退会した場合、投稿した写真の原本は削除するが、
  **生成済みの作品の中の当人の区画（減色されたピクセル）は残す**方針
- 画面（S-17）と文言（`delete.body`）で、この旨をユーザーに明示している

### 関連法令

個人情報保護法 第35条。

- 第1項: 第18条（利用目的による制限）・第19条（不適正利用の禁止）・第20条（不適正取得）に
  違反する場合、利用停止・消去を請求できる
- 第5項: **利用する必要がなくなった場合**、または**本人の権利・正当な利益が害されるおそれ**が
  ある場合にも、利用停止等を請求できる
- 免除規定: 利用停止等に**多額の費用を要する場合その他行うことが困難な場合**であって、
  本人の権利利益を保護するため必要な**代替措置**をとるときは、この限りでない

### こちらの立場（2案）

**案1: 「困難」の免除規定に依拠する**

作品は多人数の共同生成物であり、1人の区画を除くと作品全体が変質する。
また預かり手が既に決まっている作品を作り直すと、第三者の利益を害する。

→ **⚠️ この主張には弱点がある。** 要件定義書 §4.7 で、削除要請に応じて
特定のシールを VoidCell 化して再生成する仕組みを**すでに実装している**。
技術的手段が存在する以上、「困難」の主張は通りにくいと考えられる。

**案2: そもそも「本人が識別される保有個人データ」に当たらないと構成する（推奨）**

- 生成後のタイルは、32色に減色された数十〜数百ピクセルの色の塊であり、
  それ単体では個人を識別できない
- 識別を可能にしているのは `region_map`（user_id → 矩形座標の対応）である
- したがって**退会時に画像を再生成せず、`region_map` の対応を切る（匿名化する）**ことで、
  「本人が識別される」状態を解消できる可能性がある
- 作品は保持され、当人との紐付けだけが消える

この案なら、S-17 の「作品に残るもの」の説明を
「あなたと結び付かない形で、色として残ります」に近い表現へ調整することになる。

### 弁護士に確認すべき問い

1. 案2の構成（region_map の切断による匿名化）は、35条5項の請求に対する対応として成立するか
2. 匿名加工情報／仮名加工情報の枠組みを使う余地はあるか
3. 案2でも不十分な場合、投稿時の利用許諾で「生成物からの分離不能性」に同意を得ておけば足りるか
4. S-17 の現在の文言（「あなたが記録した311日は、そのアトリエの作品の中に残ります」）は
   説明として適切か。修正すべき表現はあるか
5. 退会後も残ることを、投稿の都度ではなく登録時の同意で足りるとしてよいか

### 成立しなかった場合の設計変更

退会時に §4.7 の再生成フローを適用し、当人の全区画を VoidCell 化する。
影響: 過去の作品が事後的に変化する。預かり手への通知が必要。
「描き直さない」という原則の例外を1つ認めることになる。

## B. ★写真の利用許諾の範囲

### 事実関係

- ユーザーの写真（シール）は、合成作品の素材として使用される
- 作品は、生成・展示・アーカイブ・書き出し（透かし入り）の対象になる
- **Phase 3 では、全生命シールトを外部へ販売し、売上を参加者へ分配する構想がある**
- さらにアレンジアート（派生作品）の販売、期間限定IPコラボも想定している
- 生成物の権利は運営に帰属させる想定だが、明文化していない

### 関連論点

- シールトはユーザー写真の**二次的著作物**に当たる可能性が高い（著作権法27条・28条）
- 素材が多数のため、各ユーザーが共有著作者となるのか、
  それとも生成という運営の行為に創作性を認めるのかが問題になる
- Phase 3 の販売は、許諾範囲が狭いと実施できない

### 弁護士に確認すべき問い

1. 生成されたシールトの著作権を、運営に単独帰属させる構成は成立するか。
   それとも各ユーザーとの共有になるか
2. Phase 3 の販売・分配まで見据えた場合、投稿時の利用許諾に何を含めるべきか
   （複製・翻案・公衆送信・譲渡・二次利用・サブライセンス・著作者人格権の不行使）
3. 分配（KUUN還元）は、許諾の対価として構成すべきか、それとも別建ての報酬か。
   前者なら消費税・源泉徴収の扱いはどうなるか
4. IPコラボで第三者のIPを混ぜる場合、ユーザー写真との関係で追加の許諾が要るか
5. **無償配布の一次流通に対して、将来の有償販売を含む許諾を最初から取ることに問題はないか**
   （Phase 1 で「販売しない」と明示しながら、規約で販売の許諾を取る構造の是非）

### 補足

要件定義書 §6.4 の語彙ポリシーにより、Phase 1 では将来の経済圏を告知しない方針である。
一方で規約には販売の許諾を含める必要がある。**この不一致が問題にならないか**を
特に確認したい。

## C. ★第三者の写り込み（肖像権・プライバシー）

### 事実関係

- 写真はアプリ内カメラでのみ撮影される（1080×1080固定）
- 投稿時に自動審査を行い、確信度が高い場合のみ除外する
- **投稿者からの異議申立の仕組みは持たない**（v0.7で廃止）
- 除外の閾値は「迷ったら通す」方向に振る方針（要件定義書 §10.4）
- 写り込んだ本人からの削除要請があれば、§4.7 の再生成フローで対応する
  - 現行版を退避し、当該区画を VoidCell 化して再生成
  - 旧版は90日で画像実体を破棄（異議係属中は停止）

### 調査で判明した事実

情報流通プラットフォーム対処法（2024年5月公布、2025年4月施行）について:

- 大規模特定電気通信役務提供者の指定要件は**平均月間発信者数1000万人以上**等
- 2025年4月時点の指定は Google LLC、LINEヤフー、Meta Platforms、TikTok Pte. 等
- 義務の内容は、**権利を侵害されたとする者**からの削除申出窓口の整備・公表、
  調査義務、一定期間内の通知、運用状況の透明化
- **したがって、この法律が求めているのは被侵害者向けの窓口であり、投稿者からの異議申立ではない**

→ **要件定義書 §10.4 の記述を修正すべき。** 異議申立の廃止と情プラ法は直接関係しない。
Schiild には既に §4.7 の削除要請フローがあり、そちらが情プラ法の想定する仕組みに対応する。

### 弁護士に確認すべき問い

1. 除外閾値を「迷ったら通す」方向に振る方針は、写り込んだ第三者に対する
   注意義務との関係で妥当か。むしろ厳しくすべきか
2. 削除要請への対応期間の目安。§4.7 に具体的な期限を定めるべきか
3. **旧版の90日保管は妥当か。** 削除対象物そのものを保管することのリスクと、
   紛争対応のための必要性のバランス
4. 規約に、他人の写り込みについてユーザーの責任を定める条項を置くべきか。
   置いた場合でも運営の責任は残るか
5. 大規模化した場合に備え、いま時点でどの体制を先取りしておくべきか

## D. モデレーション除外に異議申立を持たないこと

### 事実関係

- 自動審査で除外されたシールは、その日の作品に永久に含まれない
- 投稿者に理由を通知するが、異議申立の導線は置かない
- 通知画面（S-11）では、判定の可謬性に言及せず、
  「一度確定した作品を描き直さない」という原則を理由として示している

### 現状の評価

- 情プラ法の対象外（C参照）
- Apple/Google のガイドラインは、UGCについて**通報の仕組みと迅速な対応**を求めるが、
  投稿者への異議手続きまでは要求していないと理解している（要確認）
- **EU展開時はDSAが内部異議処理手続を求めるため、方針の変更が必要になる**

### 弁護士に確認すべき問い

1. 国内法上、投稿者への異議手続きを持たないことに問題はあるか
2. 消費者契約法上、事業者の一方的な判断で役務提供を制限する条項として
   不当条項に当たる余地はないか
3. Apple/Google の審査で問題になる可能性はあるか

## E. 未成年の扱い

### 事実関係

- Phase 1 は完全無課金。年齢による機能差を設けていない
- 写真投稿SNSであり、他人の写り込みが生じうる
- Phase 2 で eKYC と課金が入る（公式シールダーは18歳以上とする想定）

### 弁護士に確認すべき問い

1. Phase 1 で年齢確認をどこまで行うべきか
2. 保護者の同意を要する場面はあるか
3. 青少年インターネット環境整備法との関係
4. ストアのレーティング区分への影響

## F. Phase 2 以降の金融規制（着手前に再相談）

一次配布を無償化したことで、Phase 1 の金融規制リスクは大幅に縮小している。
以下は Phase 2 着手前に改めて相談する。

| 論点 | 内容 |
|---|---|
| 資金決済法 | KUUN を譲渡不可・換金不可のポイントとして設計する。前払式支払手段に該当しないか |
| 同上 | Tier2未満ユーザーの「未確定KUUN」が債務として扱われないか |
| 金商法 | 二次流通と分配が集団投資スキーム持分に当たらないか。「創作への対価」構成の成否 |
| 犯収法 | eKYC と取引時確認の要否 |
| 賭博罪 | 一次配布が無償・応募無料の抽選であることで解消されているか |
| 景表法 | 分配の表示方法 |
| 特商法 | 有料機能の表記義務 |
| ストア規約 | デジタルコンテンツ販売のアプリ内課金経由の要否と、外部課金導線の可否 |

## G. Phase 3 の販売と分配（構想段階）

全生命シールトを外部販売し、その日の全参加者へ分配する。
**再分配の主エンジンであり、コンセプトの中核**であるため、実現可能性を早めに確認したい。

### 弁護士に確認すべき問い

1. 数万〜数百万人の写真から生成した作品を販売することは、
   B の許諾さえ整えば可能か
2. 全参加者への分配は、法的にどう構成すべきか（許諾対価／報酬／その他）
3. 分配額が少額多数になる場合の実務上の障害（源泉徴収、支払調書、消費税）
4. 「売上を全員に還元する」という訴求が景表法上問題にならないか

## I. 要件定義書へのフィードバック（本調査で判明した修正点）

1. **§10.4 の記述を修正する。** 「情報流通プラットフォーム対処法は大規模事業者に
   削除申出への対応体制を求めている」ため異議申立の再導入を検討する、と書いているが、
   同法が求めるのは被侵害者向けの窓口であり、投稿者の異議申立ではない。
   §4.7 の削除要請フローが対応する仕組みである。
   異議申立の再導入は **DSA（欧州展開時）のみを理由とする**のが正確。

2. **§10.2 の削除権の記述に、案2（region_map の切断）を追記する。**
   「§4.7 の再生成フローを退会時にも適用する」という現在の代替案よりも、
   作品を保持できる分だけ設計への影響が小さい。

3. **§4.7 に、削除要請への対応期限を項目として追加する**（値は相談後に決定）。
