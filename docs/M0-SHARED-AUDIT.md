## 判断が必要な主な差分

- capacityHint / invalidAtelier: 2〜2000の自由入力に対し、正式S-14は2 / 5 / 12 / 20の選択。名前1〜40文字はS-14に根拠を確認できない暫定制限。
- retake: 「撮り直す」は onboarding.1.body の「撮り直しも…できません」と不一致。撮影失敗の再試行と正常撮影後の撮り直しを区別する必要がある。
- confirmBody / confirm: ローカル記録の説明に対し、正式は投稿先 {ateliers} の読み上げと「確定する」。文字列だけの置換では送信済みとの誤認を招く。
- add / added / recorded: 端末内の追加記録に対し、正式は投稿済み・投稿先追加の表示。posted.addedは {n} を使う。
- saveError: ローカル保存の失敗。camera.upload_retryは送信の失敗であり同一事象ではない。
- delete* / disappears* / remains*: 試作は端末データ削除。正式はアカウント削除と生成済み区画の残存、ハンドル確認。S-17の必須カードなどは文言キー自体にも不足がある。
- noWorks / noWorksHint: 未接続を説明する試作文言。正式empty.archive.*は本番の翌朝生成を前提とする。
- brand等、同一文字列の正式キーがない項目には、一般ラベル、試作専用表示、入力検証エラー等が混在する。独自文言を正式値として扱わない。

この報告では値の置換やM1以降の実装を行わない。資料内の不一致の追加調査はユーザーへの応答で報告し、SOURCE-REVIEW.md は変更しない。
