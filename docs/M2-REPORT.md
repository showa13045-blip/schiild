M2は`m2-server`ブランチで着手。M1のPR #2が未マージのため、そのブランチを土台に差分を分離する。M2全体は未完了。

## 今回の基盤

PostgreSQL 16のPhase 1マイグレーション、チェックサム付き適用ツール、ローカルseed、ER図、実DB制約テストを追加した。

確認済み: 同日2枚目の拒否、UTC 23:59/00:01の別日判定、セッションtimezoneからの独立、作品IDを写真FKへ入れた際の拒否、他人の写真の拒否、重複投稿・アトリエ作品・全生命作品の拒否、履歴DELETE/TRUNCATE/更新の拒否、アプリ用ロールからの削除拒否。マイグレーションは2回実行して二重適用されないことを確認した。
