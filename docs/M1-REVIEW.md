# M1 レビュー事項

## 承認済み

- 部分再生成は前版stateを使い、対象外の画素と初回メタデータを保持する。
- バケットのJPEG検証・平均色計算を投稿時に分離し、日次CLIの入力読込から成果物保存までを200msの対象とする。
- M1は解析的な暫定32色パレットで評価する（MILESTONES.md）。実写真の本番パレットは後続の評価事項。

## 確定した実装規約（2026-09-08承認）

仕様の擬似コードで未定義の箇所を具体化したもの。ユーザーが「この規約でM1を確定する」と回答し、以下の採用を承認した。原文の仕様書は書き換えていない。

| 項目 | 現在の実装 | 影響 |
|---|---|---|
| 空バケット補間 | Manhattan距離の近い占有座標を最大4点、等重みで平均。同距離は行順起点のBFS順、端の折返しなし。全空はVoidCell | 初回生成時の空き領域の色を決める |
| VoidCellノイズ | 専用ChaCha20で全画素を行順に走査。1/16で2番目に暗い色、それ以外は最暗色 | 未投稿領域の模様を決める |
| バージョン署名 | バージョン文字列のSHA先頭4バイトを32色のインデックスへ変換し、各隅から内向きに横4画素 | 隅の画素を上書き。再生成時も同一 |
| メタデータ | symmetry_scoreは左右鏡像の一致率。dominant_hueはパレットヒストグラムで重み付けしたOklab平均の色相。void_ratioは未投稿スロット率 | 数値の意味と後続APIの表示契約を決める |
| 乱数・丸め | ChaCha20のu32抽出、棄却法、Fisher–Yates。面積上位45%は切捨て・最少1件、同面積は安定順。分割位置は半端を上へ丸める | 別実装での再現に必要。Rust/WASMで共有 |
| ガターの試験規約 | CLI既定0。1〜3は基底キャンバスの内側右端・下端へのinset。細いタイルが消える場合あり | 本番値は未決。0〜3比較画像で評価可能 |

ガター0を本番採用とみなさず、M1のCLI既定値として扱う。本番パレット・ガター・実写真G-4判定は未確定のまま追跡する。規約変更を受け入れる場合は決定性の基準成果物とバージョンの扱いも見直す。
