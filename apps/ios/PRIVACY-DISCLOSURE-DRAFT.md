# プライバシー申告の準備

2026-10-27。公開前の確認用。App Store Connectの申告は未完了。
現行配信コードとAppleの[App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)を照合する。

## ソース照合で確定した項目

実配信のベース `worker.js`（SHA-256 `0bc9a34e5dc4357e7445e849866d88aa913cd8ea2e2ea7af275556063dbd4f73`）を確認。
実際の利用者レコードや秘密情報は取得していない。

- 11052〜11055行の `sender` はWhatsAppの送信元番号を受け取り、チャネルと番号からハッシュを計算する。
- 11110〜11111行ではその値を `whatsappSubject` としてアカウントへ永続保存し、ログイン照合に使う。電話番号そのものを保存しないことを「電話番号の収集なし」の根拠にしない。
- 11770〜11771行は、アトリエの名前・コンセプトを `rooms/` に永続保存する。「その他のユーザーコンテンツ」に該当する実データが存在する。
- 11309行は、利用者が変更した表示名をアカウントへ保存する。
- 写真は写真保存領域へ格納し、ユーザーIDに結び付いた投稿・作品を生成する。

確認済みの「名前・電話番号・写真またはビデオ・その他のユーザーコンテンツ・ユーザーID」はApp Store Connectに下書き保存済み（未公開）。
いずれも用途はアプリの機能、アカウントに関連付け、広告トラッキング用途なしとして下書き。
メール・サポートや外部サービスの保存範囲の最終確認も行い、下書きを完成した申告と扱わない。

| データ | 実際の扱い | 申告候補 |
| --- | --- | --- |
| 表示名 | LINEから受領する表示名、Appleで入力した名前、プロフィールで変更した名前を保存 | 名前、ユーザーに関連付け、アプリの機能 |
| アカウントと認証の識別子 | 内部ID、LINEチャネル内識別子のハッシュ、Apple subject、WhatsApp識別子のハッシュを保存 | ユーザーID、関連付け、アプリの機能 |
| WhatsAppの番号 | 受信メッセージ処理時に番号またはBusiness-scoped IDを取得。番号由来のハッシュと下4桁を認証に利用 | 電話番号（ハッシュも対象）、関連付け、アプリの機能 |
| 写真 | カメラ撮影した写真、生成作品、サムネイルをCloudflareに保存 | 写真またはビデオ、関連付け、アプリの機能 |
| アトリエ情報 | 名前、コンセプト、参加・投稿・生成・抽選記録を保存 | その他のユーザーコンテンツ等、関連付け、アプリの機能 |
| メール | 現行Apple登録レコードにメールは保存しない。旧Googleアカウント等の保存状況と認証処理での受領を確認 | メールアドレスは実際の収集範囲を最終確認 |
| 認証セッション | 端末／ブラウザのランダムな資格情報と、サーバー側のハッシュ・有効期限を使用 | ユーザー／端末レベル識別子の分類を最終確認 |
| 問い合わせ | 公開メールへ利用者が送る内容 | サポート情報。任意開示の例外要件も照合 |

目的はログイン、写真の共同制作、履歴表示、アカウント保護、サポート。
広告配信・データブローカーへの提供・他社データとの広告目的の照合は実装していない。
「データを収集しない」とは申告しない。写真から顔認証や位置情報の抽出は実装していない。

保存先・処理先:

- Cloudflare: アプリ配信、API、認証セッション、アカウント、画像と共同作品。
- Apple / LINE: 各プロバイダーの認証とアカウント削除時の連携解除。
- WhatsApp / Metaおよび現在のWebhook配信基盤Kapso: 利用者が送る認証用メッセージ。
- 端末: セッション情報、表示・言語・演出設定等。ネイティブのApple認証はOSのAPIを利用。

削除時は元写真とアカウント・プロフィール・連携情報を消去し、セッションを無効化。
共同作品と区画・縮小されたGLOBAL画像はアカウントと切り離して残す。
失効した資格情報のハッシュと削除済みフラグを保持し、旧セッションの復活を防ぐ。
他社側の認証・メッセージ履歴は各社側の管理であり、Schiildの削除で全社の履歴が消えるとは説明しない。

未確認の保存期間・ログ保持日数・法的保証を勝手に追加しない。運営窓口・画像審査の
方式が確定した後、公開中のprivacy.htmlを実態に合わせて改訂する。

## 第三者側で残る確認

[Kapsoの公式プライバシーポリシー](https://app.kapso.ai/privacy)は、メッセージ・連絡先・Webhook記録等を保持する場合があると記載。
Freeプロジェクトのモデル改善利用は既定で有効、アカウントから無効化可能としている。
2026-10-28 JSTに実プロジェクトを確認。Free、会話保存Keep everything、モデル改善オフ、音声文字起こしOff、ログ保存オンだった。
設定の確認なしに「学習利用なし」「認証メッセージを保持しない」と申告しない。
ログイン処理のメッセージ内容・カスタマーサポート等を必要に応じて追加し、用途も見直す。
Kapso自身の管理画面アクセス分析とSchiild利用者のデータ処理は区別し、一律に全種類を申告しない。

## 2026-10-27の追加

投稿ルールへの同意バージョン・日時、公開前確認の待ち状態・判断・記録をCloudflareで保存する。

Kapsoのモデル改善は2026-10-28 JSTの管理画面でオフを確認。すでにオフだったため設定の切り替えはしていない。将来の利用への適用であり、過去利用の有無やメッセージの非保持を保証しない。
電話番号はAppleの非公開の審査連絡先へ本人がブラウザで入力し、チャットやGitへ出していない。
