# App Store 公開準備・EU提供保留

更新: 2026-10-27（日本時間）。審査提出・一般公開はまだ行っていません。

## 配信方針

- 無料。EU加盟27か国は App Store 配信対象から除外し、148か国・地域を対象として保存済み。承認後は手動公開へ変更・保存済み。
- 将来追加される国・地域への自動配信も無効化。EUでの提供再開は別途判断する。
- `schiild.app` のWeb版はEUからも利用可能。地域アクセス制限は追加していない。
- 提供者は事業者であると本人が回答。非事業者として申告しない。
- AppleへのDSA事業者情報の提出・認証は未完了。住所・電話番号の公開手続きは進めていない。

除外国: アイルランド、イタリア、エストニア、オーストリア、オランダ、キプロス、

## DSAの準備事項

AppleはEUストアの事業者について住所・電話番号・メールの確認と表示を求める。
配信地域を外すことと、事業者区分の申告は別の手続きとして扱う。
公開連絡先の選定・確認と、最終申告は本人による再開判断を待つ。

| 確認事項 | 現状・次に必要なこと |
| --- | --- |
| Appleの事業者情報 | 公開に使う住所・電話・メールを本人が決定。証明・確認を経て申告する。未提出。 |
| サービスの法的分類 | [ASSUMPTION] 写真を保存し共同作品を公開するため、ホスティング／オンラインプラットフォームに当たる可能性がある。EUへのサービス提供・対象化、規模による例外を含め適用を確認する。 |
| 当局・利用者の連絡窓口 | DSA第11・12条の対象となる場合の連絡先、対応言語、受付・回答手順を決める。未整備。 |
| EU域内の法定代理人 | EUに拠点がない場合、第13条の適用と代理人の必要性を確認する。選任・契約は行っていない。 |
| 利用条件とモデレーション | 第14条に沿い制限・判断・自動処理・人による確認を説明する準備が必要。既存の法務メモを適合証明として扱わない。 |
| 違法コンテンツの通知と対応 | 第16条等の適用確認。作品・日付・位置を特定できる通報、受付通知、判断記録と理由通知の設計・運用を準備する。未実装。 |
| 異議申立て等 | プラットフォーム向け義務と規模による例外を確認し、必要な申立て・再検討・記録手順を定める。未実装。 |

EUのApp Store配信保留だけでWeb版に関するDSAの検討が不要になるとは扱わない。
上記は準備項目であり、DSA適合を確認済みという意味ではない。未確定の規約・対応期限・
法的分類を実装側で決めない。

## 2026-10-27の追加対応

- 審査連絡先の電話番号をブラウザで本人入力し、連絡先一式の保存を確認。電話番号はチャット・Gitへ出力しない。
- 隔離したApp Reviewモードを公開。審査専用ID・パスワードと操作説明をAppleの非公開審査欄へ保存した。通常データと外部認証は保持。
- 通常／審査のセッション・画像・アトリエ・作品・端末保存を分離。通常APIが審査用資格情報を拒否することを検証。
- 公開環境の審査専用データで、単色の自作テスト画像を使い、投稿→確認待ち→運営者確認→承認→生成→削除→空での再登録を検証した。
- 公開前確認は本人が運営者確認を選択し、担当するSchiildアカウントを指定。アカウントの実在を確認し有効化した。
- 元写真は担当者と本人だけが閲覧でき、承認前は共同作品・GLOBALに出ない。確認担当者の一覧は25件ずつ表示する。
- 本人の追加指示により、翌日以降の承認も元の日付へ反映する。対象区画だけを更新し、他の画素・既存の預かり手を維持する。
- 確認待ちの区画を同日中に他人が利用できないようにした。削除時は未承認の元写真・確認待ち・同意記録も消す。
- 投稿ルールの本文、限定した許諾、10言語の短い説明と同意確認、同意バージョンを追加。既存投稿への同意は捏造しない。
- 直近の確認では、型・禁止語チェック、アプリの173テストと共通17テストが成功。環境依存7件はスキップ。Rustの既存テスト0件も成功。
