# AGENTS.md — 共有パッケージ

型・定数・i18n・WASM ラッパを置く。

## 文言

文字列は `docs/copy.md`（UI文言集 v1.2）にキーがある。**自分で書き足さない。**
必要なキーが無い場合は創作せず `[ASSUMPTION]` として報告すること。

### 禁止語

所有 / オーナー / 売却 / 出品 / 投資 / 利回り / 値上がり / リターン / 資産 /
レア度 / ランキング / 達成 / 未達 / 頑張り / お疲れさま / ぜひ / さあ

**感嘆符を使わない。** `pnpm lint` で機械的に検出できるようにすること。

### 原則

- 「所有」ではなく「預かる」
- 空状態で謝罪しない
- 失敗はまず事実、次に「記録は無事」
- 達成ではなく記録の書式（「7人が投稿しました」ではなく「7 of 12 が今日を記録」）
- `common.of` は日本語化しない。等幅表記の一部として台帳の書式を保つ
- 個人を名指しで催促しない
- 不可逆は事実として告げる（「本当に投稿しますか」ではなく「今日のシールは一度きりです」）
- 当選を祝わない。運で決まったものを称賛すると、外れた人への含意が生じる

### プレースホルダ

`{n}` `{date}` 等は i18n の補間で扱う。**文字列連結で組み立てない。**
`\n` を含むキー（`fail.title` `excluded.title`）は改行位置を確認すること。

## 型

`SchiilId` と `SchiildId` を branded type で分ける。素の `string` を境界を越えて渡さない。
WASM の BSP ラッパもここに置く。TypeScript で分割ロジックを再実装しない。
